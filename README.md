# Overly Honest Resume Generator
A lightweight, hilarious web app that generates brutally honest corporate resumes based on real world inputs.
Built for the Hack Club **Stardance** mission!

**Live Demo:** [https://sonical015.github.io/Overly-Honest-Resume-Generator/] 

---

## Features
- **Custom Form:** Takes your real name, desired job title, true motivation and favorite workplace distraction.
- **Honest Logic:** Generates funny corportae resumes and daily duties automatically.
- **Print Support:** Includes a built-in print button formatted to print out the developed resume.

---

## Tech Stack 
- **HTML 5:** Layout and input forms
- **CSS3:** Modern card design with google fonts(`Inter`)
- **JavaScript:** Dynamic DOM Manipulation and "window-print()" funtionality
